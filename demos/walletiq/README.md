# WalletIQ — Demo

Demo interactiva de una aplicación de finanzas personales. Muestra un panel de saldo, movimientos y presupuesto, con registro local de gastos.

## Herramientas
- HTML5
- CSS moderno (Grid, variables y responsive design)
- JavaScript nativo
- Datos ficticios en el navegador; no guarda información real

## Ejecutar
Abrí `index.html` en un navegador o serví la carpeta con cualquier servidor estático.
