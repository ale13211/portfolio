# SalesClose — Demo

Dashboard demostrativo para gestionar leads, conversaciones y métricas de venta por WhatsApp.

## Herramientas
- HTML5
- CSS moderno y responsive
- JavaScript nativo para la interacción del pipeline
- Datos ficticios; no integra la API de WhatsApp en esta demo

## Ejecutar
Abrí `index.html` o usá un servidor estático.
