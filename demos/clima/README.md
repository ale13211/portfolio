# ClimaPy — Demo

Una interfaz meteorológica responsive para consultar condiciones actuales, pronóstico por hora y previsión semanal de Paraguay.

## Herramientas utilizadas

- HTML5 semántico
- CSS moderno: gradientes, Grid, responsive design y microanimaciones
- JavaScript nativo para selector de unidades, cambio de ciudad y renderizado de datos
- Datos de demostración locales

## Próxima integración

La interfaz está preparada para consumir una API pública como [Open-Meteo](https://open-meteo.com/) y mostrar clima real por geolocalización.

## Ejecutar

Abrí `index.html` en el navegador o serví la carpeta con cualquier servidor estático.
