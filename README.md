# Portfolio de Alejandro Insfran

Portfolio personal de **Alejandro Insfran**, desarrollador de datos y sistemas. Presenta experiencia en entornos financieros, proyectos full-stack y las tecnologías que uso para convertir reglas de negocio complejas en productos claros y confiables.

## Diseño

El sitio usa una composición tipo **bento grid**: bloques modulares con jerarquía visual clara, alto contraste y una experiencia rápida tanto en escritorio como en móvil. La referencia fue la organización visual de portfolios contemporáneos, pero la implementación, el contenido, los colores y la identidad son propios.

## Tecnologías

- HTML5 semántico
- CSS moderno: Grid, variables, gradientes, responsive design y animaciones ligeras
- JavaScript nativo para navegación suave y detalles de interfaz
- Google Fonts: Manrope y DM Mono
- GitHub Pages para publicación estática

## Ejecutar localmente

No requiere instalación ni dependencias. Abrí `index.html` en el navegador o servilo con cualquier servidor estático.

```bash
npx serve .
```

## Personalización

- Editá el contenido principal en `index.html`.
- Ajustá colores, espaciados y puntos de quiebre en `styles.css`.
- Reemplazá los CV en PDF manteniendo los nombres actuales, o actualizá los enlaces del encabezado.
- Actualizá las URLs de demos, LinkedIn y GitHub antes de publicar.
